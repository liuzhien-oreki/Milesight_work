## Publishing
Push these files to the main branch of the target GitHub repository. In Settings → Pages, select GitHub Actions as the publishing source if needed. The included workflow deploys the website on every push to main.

## Content editing
Presenter-guide edits are saved only in the current browser. Download the Markdown and replace USER-GUIDE-AND-SPEAKER-NOTES-ZH.md in the repository to publish shared updates.
